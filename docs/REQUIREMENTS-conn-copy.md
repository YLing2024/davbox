# 需求：连接信息逐项复制

## 背景

davbox 管理页的「连接信息」弹窗（`web/src/admin/AdminPage.tsx` 里的 `ConnModal`）现在只提供三行只读文本：

```
地址    https://…
用户名  …
口令    …
```

底部有一个「复制连接信息」按钮，一次复制全部三行（格式 `地址：…\n用户名：…\n口令：…`）。

实际使用时，App 的 WebDAV 设置是**分字段填**的（地址一栏、用户名一栏、口令一栏），整段复制还得自己剪开。因此需要**每一行各自一个复制按钮**。

## 要做的事

1. **每一行加独立复制按钮**：地址、用户名、口令三行各自在行尾加一个小图标按钮，点一下**只复制该项的值**（不含标签、不含换行）。
2. **保留原有的整段复制按钮**（`复制连接信息`）不动：它复制三行拼好的文本，行为与格式保持不变。
3. **反馈互相独立**：点某项复制后，只该项按钮进入「已复制」态，约 1.6 秒后恢复；整段按钮的「已复制」态与逐项按钮互不影响。
4. **无障碍**：按钮用 `<button type="button">`，带 `aria-label`（如 `复制地址` / `复制用户名` / `复制口令`）与 `title`；复制成功后 `title`/`aria-label` 可变为「已复制」以给出可读反馈。
5. **口令行保持明文显示**（现状如此，本需求不改）：不要顺手加「隐藏口令」开关。

## 实现约束

- **复用** 文件内已有的 `copyText()`（含 `navigator.clipboard` + `execCommand` 兜底），不要引入新依赖，`package.json` 依赖项不得变化。
- 图标：在 `web/src/icons.tsx` 新增 `IconCheck`（与现有图标同风格：16px、`currentColor`、线性描边）。
- 样式：
  - `.conn` 现在是 `grid-template-columns: 72px 1fr`；加一列给按钮（例如 `72px 1fr auto`），按钮用既有 `.icon-btn` 风格，不要引入新的视觉语言。
  - 值列仍要保持可换行（`word-break: break-all` 不变），窄屏不能溢出或把按钮挤出画面。
  - 不用 emoji，不加多余说明文案（Swiss 极简风格）。

## 验收（必须自己跑真命令并给出输出）

1. `cd web && npm run build` 通过（`tsc --noEmit` + `vite build`，零类型错误）。
2. 真机路径自测（可以起本地服务或用构建产物）：打开管理页 → 点某个账号的复制图标打开「连接信息」→ 逐项点复制 → 剪贴板内容分别等于该项的值（口令含特殊字符也要原样）。
3. 整段「复制连接信息」仍然可用，文本格式与改动前一致。
4. 窄屏（≈375px 宽）下弹窗不横向溢出。

## 铁律（必须遵守）

- 只允许改 `/root/proj/davbox` 内的文件。
- 小步多次 `git commit`（conventional commits）；**禁止** `git push`、**禁止** `git checkout -b`（就地留在当前分支）、**禁止** `rebase` / `reset --hard` / `merge`。
- **禁止** `systemctl` / `service` / `kill` / `pkill` / `fuser -k`。
- 所有命令都要带 `timeout`。
- 仓库内**不得出现**任何真实域名、真实 IP、口令或密钥；测试/示例一律用 `dav.example.com`、`127.0.0.1`。
